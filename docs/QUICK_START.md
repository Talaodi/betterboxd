# Betterboxd Quick Start

Betterboxd 是跑在本机的一个影迷记录工具: 它有一个 Web 界面, 一个本地 SQLite 数据库, 以及一个可以对话的 AI 助手. 所有数据都存在你自己电脑上, 服务只监听 127.0.0.1:3000. 

本文按使用顺序介绍每个功能能做什么, 以及在哪里做. 更基础的编译与运行问题见上级 README.md. 

---

## 1. 启动之后: 存档选择界面

打开 http://localhost:3000 后, 首先看到的是存档选择界面. 一个存档等于一套完整的数据: data.db, config.toml, sessions, posters, 全部放在同一个 `.betterboxd/` 目录里. 不同存档之间互不影响. 

- 列表里的每一项可以 "进入", 也可以"删除" (彻底删除, 连同文件夹). 
- 列表按最后使用时间排序. 
- "新建存档" 选择父目录和存档名, 会在该目录下创建 `<存档名>/.betterboxd/`. 
- "载入已有存档" 指向一个已经存在的目录 (之前手拷出去的, 或者历史备份). 
- 选中一个存档之后, 本次浏览器会话内不会再出现这个界面; 下次刷新或重启应用时会再次出现. 

如果还没有任何存档, 界面是空的, 只能新建或载入. 

## 2. 设置页: 连接 AI 和 TMDB

第一次进入需要两件事. 

### AI 配置

设置页 -> 模型配置 -> "+ 添加配置". 填写:

- Name: 配置名, 例如 "deepseek". 
- Endpoint: API 地址, 写到 `/v1` 为止, 不含 `/chat/completions`. 例如 `https://api.deepseek.com`. 
- API Key: 你的密钥. 保存后卡片上只显示脱敏形式 (前后几位加 ***). 
- Model: 模型名. 
- Context Length / Max Tokens / Temperature / Top P: 选填, 有默认值. 

价格与预算 (选填):

- 输入 (缓存命中) / 输入 (未命中) / 输出 (缓存命中) / 输出 (未命中): 每 1M token 的价格. 缓存命中的输出极少见, 保持 0 即可. 
- 货币: CNY 或 USD. 
- 用量上限: 填了就按 "缓存用量" 判断, 达到即中断本轮请求; 不填不限制. 

界面下方还有两处:

- "总用量": 该配置历史上所有调用花费的和, 不可重置. 
- "缓存用量": 当前周期计数器, 每次调用累加. 预算判断只看它. 点击 Reset 清零, 等于重新开始预算周期. 

每个配置卡片上有: 切换 (设为当前), 编辑, 删除, Reset. 删除当前配置时, 会自动把活动配置切到列表里的下一个, 不会留空引用. 

点击 "+ 添加配置" 会直接打开编辑弹窗 (而不是先加一个空条目). 如果当前没有任何活动配置, 新建保存后会自动启用.

### TMDB 配置

设置页 -> TMDB -> API Key, 一行, 保存即生效, 无需重启. 影片搜索与元数据靠它.

### 未配置 AI 时的行为

- 打开任何新会话, AI 的第一条消息不会生成, 页面显示一条错误提示: "尚未配置 AI 模型...". 
- 在输入框发送消息时, 也会弹出同样的提醒 (前端即时检查).

## 3. 对话 (Chats 页)

左侧是会话列表, 右侧是聊天面板. 

列表顶部有三个标签:

- 全部记录: 所有会话. 
- 电影记录: 一切挂了影片 (movie_id) 的会话, 包括从影片页 / Diary / Review 进入的讨论. 
- 同主题记录: 当前打开会话的锚点过滤 (某个影片的多个话题集中在一起). 

操作:

- "+ 新建" 新开一个控制台会话. 
- "导入" / "导出": 本项目私有的 JSON 格式, 用于备份或迁移. 
- "✎": 修改当前会话标题. 标题默认自动生成. 
- 删除会话: 面板标题行右侧"删除". 

### 控制台会话

新建后 AI 会主动发第一条消息, 一般是固定的自我介绍 (它能做什么, 以及给 2-3 个例子). 你可以:

- 说 "记一下: 昨晚看了"X", 76 分" 之类, AI 先用搜索确认影片, 再有写操作. 
- 问统计: "今年看了多少部", "我常去哪家影院", "王家卫的电影我打过多少分". 统计由 AI 现场写 SQL, 在只读视图上执行, 上限 1000 行; 结果以表格或图标返回. 
- 聊影片: 剧情, 导演, 题材, AI 会先查 TMDB 再谈, 不凭记忆编. 
- 要推荐: "基于我的口味推荐几部是枝裕和", AI 读画像 (lookup 统计  最近观看), 用 search_person_movies 找作品, 排除已看的, 给理由. 
- 操作清单: "把 X 加进我 2026 十佳候选" 等. 

写操作 (记一笔 / 改笔记 / 加清单...) 都会弹出一张确认卡, 卡片上的参数可以当场改, 确认后才入库. 取消就什么都不写. 

### 从影片/记录/影评进入的会话

影片详情页, Diary 条目, Review 卡片上都有 💬 按钮, 点击后新建一个带上下文的会话:

- 影片上下文: 元数据 + 你的状态 (评分 / 想看 / 喜欢) + 最近记录. 
- Diary: 那条记录的全文 (日期 / 评分 / 票价 / 随记 / 维度 / 标签) + 变更史 (Action 史). 
- Review: 影评全文 + 变更史. 

AI 的第一条消息会基于这些内容, 点出要点, 再给 2-3 个可选讨论方向, 把选择权交给你. 

### 流式展示的细节

- 每条正式回复右下角有灰字: `[输入+输出 tok  :  币种金额]`. 若被断开(熔断/预算拦截), 会显示"⚠ 已中止: 原因".

## 4. Diary (观影记录)

列表按时间倒序. 每条记录显示: 日期, 片名, 当次评分, 是否影院 + 票价, 维度标注 (地点 / 场景 / 同伴), 自由标签, 随记. 

- 点条目展开: 随记以 Markdown 渲染 (粗体 / 列表 / 引用 / 表格都能用). 
- 条目右侧操作: 💬 (与 AI 讨论这条记录), ✎ (编辑), 删除. 
- 重看: 同一部片多次记录, 显示 "第 X 刷" (按观看日期计, 影评不算). 

编辑弹窗里可以改日期 / 评分 / 影院 / 票价 / 标注 / 标签, 随记支持 "预览" 切换. 

"维度" 是三个固定的槽位 + 自由标签:

- 地点 (家 / xxx 影院), 场景(IMAX / 重映...), 同伴 (小王/老张...). 
- 添加方式: "+ 添加标签" -> 选类别 -> 输入框带自动补全, 候选来自值池和你自己的历史值. 
- AI 在记一笔时会先查 lookup_taxonomy, 优先复用既有值 (比如 "北影节" 会落到 "北京国际电影节"), 避免同名新值碎片化. 

评分说明: 影片的最终评分不看单条记录, 而是取 "署名日期最靠后且打了分" 的那条 Diary/Review (同名日看更新时间). 改一条老记录的评分, 不一定改变影片终评, 这符合直觉: 终评应该由最新的表态决定. 

---

## 5. Review (影评)

- 标题 (选填), 正文 (必填, Markdown 支持), 评分 (选填). 
- 署名日期: 不填则默认等于创建时间, 可以在编辑时改. 终评绑定也用它. 
- 每篇卡片: 标题 / 正文 / 评分 / 署名日期, 右侧 💬 (讨论这篇影评), ✎ 编辑, 删除. 
- 正文较长时卡片默认收起, 点 "展开全文". 

---

## 6. Films (影片库)

竖排列表, 每部片有: 海报, 标题, 年份, 是否想看, 你的评分, 是否看过. 

详情页(点击影片)从上到下:

1. Hero: 背景图, 标题, 年份/时长/导演/类型, 社区评分. 
2. 元信息区: TMDB 简介独立一行展示. 
3. 状态区: 想看开关, ♥ 喜欢(只能给看过的影片), 我的终评分(只读, 由 Diary/Review 派生), 所属 List. 
4. Log 区: 三个折叠板块 Diary / Reviews / Chats. 每板块内按时间倒序, 只有该板块内容存在时才显示. 
5. Lists 区: 本片归属的清单, 直接复用 Lists 页的卡片样式, 带 "No.x in" 或 "In" 前缀, 点击可进对应清单页. 
6. "与 AI 讨论" 按钮: 新建影片话题会话. 

---

## 7. Lists (清单)

左: 清单列表 (封面卡), 右: 清单详情. 

- 新建: 名称 + 描述 + 是否排名 (ranked). 
- 详情页: 影片按序排列, 垂直卡片 (复用 Diary 风格), 每项可移出. 
- 排序: 拖拽调整顺序. ranked 清单显示排名号 (1,2,3...), unranked 也是一样的拖拽方式, 只是不显示名次. 排名由位置自动导出, 不存在手动改数字的入口, 也没必要: 拖动即改序. 
- 点影片卡进入影片详情页. 
- 归属区: 影片详情页有 "加入清单" 下拉, 可直接建新清单. 

AI 也可以操作清单 (create / update / delete / add_item / remove_item), 走确认门. 

---

## 8. Search (搜索)

- 输入关键词 (可按需加年份), 点 "搜索" 或回车, 不自动搜. 
- 结果垂直排列, 显示海报 / 片名 / 年份 / 简介预览. 
- 默认一次 5 条, 底部 "更多" 在页内追加 5 条 (同页全部数据在切换页后保留). 
- 点击结果进入影片详情页. 
- 左侧边栏第一个入口就是 Search. 

---

## 9. Stats(统计页)

统计项目都是 AI 对话里建出来的 (manage_saved_queries), 本页只是回放:

- 每个已保存项目: 名称 + SQL + 图表配置, 可以"重跑" (最新数据) 或删除. 
- 重跑结果显示 1000 行以内, 或提示截断. 

AI 写统计的约定 (prompt 里写明): 计数 / 均值 / 排序这些能用 SQL 聚合的, 必须 run_stats; 风格 / 情感 / 主题这类主观文本分析, 用 lookup_diary / lookup_reviews 自己读, 不许硬算文本. 

---

## 10. 存档与数据

- 存档列表: `~/.config/betterboxd/archives.json` (Windows 是 `%USERPROFILE%\.config\betterboxd\`, 路径实际写入). 
- 当前存档目录: 点击侧栏顶部的 📦 存档名可以查看 (只是展示, 切换要重启应用回到选择界面). 
- 备份 = 直接把整个 `.betterboxd/` 目录拷走; 恢复 = 载入那个目录. 
- 每个存档独立一份 config.toml (含 AI 配置和 TMDB key), 所以存档可以整包在不同电脑间搬. 

---

## 11. 一些细节与约定

- 输入框: 回车发送, 输入期间 AI 回复时不可发送, 点橙色 "停止" 可中断当前生成本地留档. 
- Markdown: 聊天 / 随记 / 影评都渲染. 
- 图片: 海报与剧照缓存在存档的 posters/ 下. 
- 日志与排错: 服务器 stdout 有启动 / 请求日志; 设置页不打印任何 key (其它日志里也都是脱敏的). 
- TMDB 网络错误信息: 不会包含你的 api_key (已洗掉).
- 端口被占用: 启动会重试约 6 秒, 仍失败就退出提示, 先停掉占用进程再启动.
