# 如何获取 TMDB API Key

## 注册账号

   - 打开 <https://www.themoviedb.org/account/signup>.
   - 注册完成后登录.

## 进入 API 设置页

   - 访问 <https://www.themoviedb.org/settings/api>.
   - 选择 Developer 个人使用.
   - 首次进入时可能要求填写申请理由, 可随便填写, 提交后立刻生效, 不会审核.
   - 如果报错, 可能是 API 用途有点短, 可以随便多写点.

## 复制 API Key (v3)

   - 页面左侧 **API Key (v3 auth)**，是一串 **32 位字母数字**（例如 `0123456789abcdef0123456789abcdef`）
   - 复制它。**注意**：右侧 v4 的 Bearer Token 是另一种格式，本软件不使用；请用左侧 v3 Key

## 填入 Betterboxd

   - 打开应用 → 设置页 → **TMDB** 区块 → 粘贴 `API Key` → 保存 (无需重启，立即生效).
   - 新存档需要先在建档时自动带出或在此行重新粘贴一次.

## 验证

   - Search 页搜索任意影片, 能出现搜索结果即可.
